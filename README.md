# 陇绣非遗 · 鹿望秦川

北京科技大学「鹿望秦川实践团」暑期社会实践成果 —— 一个以甘肃陇绣（庆阳传统刺绣）为主题的非遗文化宣传与数字展示网站。

## 项目简介

这是一个**纯静态的文化宣传网站**，由北京科技大学鹿望秦川实践团在暑期社会实践期间制作完成，用于展示实践团在甘肃调研陇绣非物质文化遗产的成果。

网站围绕「让非遗在新时代绽放光彩」这一目标，把实践团实地走访、影像记录所获得的一手材料整理成线上展厅，内容包括：

- 陇绣的历史源流与文化背景
- 陇绣的艺术特征与针法技艺
- 两位传承人的个人经历与独立作品展馆
- 大量刺绣作品的图文展示
- 庆阳「五绝」等地域文化背景
- 实践团自身的介绍与新媒体矩阵

它不是商业站点，也没有任何交易、投放或数据收集功能，定位始终是**社会实践成果展示页面**：让更多人看见陇绣的美、了解陇绣的故事。

## 项目背景

- **出品单位**：北京科技大学
- **实践团队**：鹿望秦川实践团（暑期社会实践项目）
- **实践主题**：甘肃陇绣的调研、记录与传播

实践团跨越千里深入甘肃天水，走访传承人、记录针法技艺、拍摄影像资料，以青年视角重新审视这门古老艺术。这个网站就是这些实践工作的集中呈现：把调研所得的文字、图片与影像整理成可长期访问、可对外分享的线上展馆，让非遗不止停留在博物馆的展柜里。

站内「鹿望秦川」板块记录了实践团的四类主要工作：实地调研、对话传承、影像记录、宣传推广，并附有快手、抖音、公众号、小红书的矩阵二维码。

### 刘云帆展馆 `liuyunfan.html`

绣者简介、绣艺人生、技法创新、匠心之作、一气化三清 3D 数字展演、作品画廊、荣誉奖状。

- **人物**：甘肃天水武山人，武山刺绣非遗代表性传承人、高级刺绣艺术师、甘肃省工艺美术大师，陇绣领军人物。曾赴苏州江南大学学习刺绣技艺，后由正高级工艺美术师梁雪芳推荐至清华大学研学，师从美术学院教授林乐成，并结识常沙娜先生。
- **代表成就**：双面绣《玉帛之路》获中国工艺美术「百花奖」金奖；《敦煌菩萨》被国家图书馆典籍博物馆收藏；《脚印》入选中国当代纤维艺术世界巡展。
- **技法风格**：南北针法融合、石窟绣艺、写意光影绣法、双面绣、文创开发，形成简约构图与凝练表现的个人面貌。
- **匠心之作**：一气化三清、石窟遗韵、陇上天马、敦煌飞天、敦煌菩萨、文创生活系列。

### 曹苑春展馆 `caoyuanchun.html`

绣者简介、绣艺人生、技法创新、匠心之作、东方微笑 3D 数字展演、作品画廊。

- **人物**：甘肃天水人，天水麦积刺绣非遗代表性传承人，敦煌研究院麦积山石窟艺术研究所馆员，获「娲乡巧娘」「乡村工匠」等称号。母亲是当地巧绣娘，父亲是麦积山石窟第一代文物修复师，被称为麦积山石窟艺术的「绣艺译者」。
- **技法风格**：敦煌劈针绣、苏州乱针绣、潮绣垫绣，以及其创造性发展的**金线立体钉绣**，另有双面绣与写意绣法。
- **匠心之作**：薄肉塑飞天、东方微笑（麦积山第 133 窟小沙弥）、窃窃私语（121 窟菩萨与弟子）、释迦会子、44 窟乙弗氏、文创生活系列。

### 3D 数字展演

两位传承人各配有一个独立的内嵌 3D 展演页，用纯 CSS 3D（`perspective` / `preserve-3d` / `rotateY` / `translateZ`）配合内嵌贴图实现作品的双面立体旋转：

- `刘云帆/一气化三清3D展演.html` —— 双面绣《一气化三清》
- `曹苑春/东方微笑3D展演.html` —— 《东方微笑》

展演以 `iframe` 嵌入展馆页面，支持鼠标拖拽旋转、滚轮缩放，并提供一个全屏沉浸式覆盖层。

## 页面与交互

均取自实际代码，未作扩展：

- **响应式布局**：`style.css` 提供 1024px / 768px / 480px 三档断点，适配桌面、平板与手机
- **移动端导航菜单**：汉堡按钮切换，点击菜单项后自动收起
- **页面滚动导航**：导航栏随滚动距离切换阴影状态
- **回到顶部**：滚动超过阈值后出现的悬浮按钮，平滑滚动
- **滚动入场动画**：基于 `IntersectionObserver`，卡片类元素进入视口时依次淡入上移
- **图片灯箱**：点击作品缩略图放大预览，支持点击遮罩或 `Esc` 键关闭
- **独立传承人展馆**：两个子页面各自完整的个人展馆
- **3D 展演**：`iframe` 嵌入 + 全屏沉浸模式切换

## 技术实现

纯静态前端，无框架、无构建工具、无后端：

- **HTML5** —— 语义化标签，`lang="zh-CN"`
- **CSS3** —— 单一样式表 `style.css`（约 1770 行），含 CSS 变量、Flex / Grid 布局、媒体查询、CSS 3D
- **原生 JavaScript**（ES6+）—— 内联脚本，负责导航、灯箱、滚动动画、3D 全屏切换，不使用任何 JS 库
- **Font Awesome 6.0.0-beta3** —— 通过 cdnjs 引入的图标字体
- **Google Fonts** —— 通过 CSS `@import` 引入 Noto Serif SC、ZCOOL XiaoWei、Ma Shan Zheng
- **GitHub Pages** —— 静态托管

站内所有相对路径均原样保留，因此从仓库根目录发布即可直接访问，无需任何路径改写。
